About This Project

Background, purpose and the statistical concepts behind Library Insights.

  • Project Title: Library Insights – Student Library Usage & Statistical Analysis
  • Purpose: This project collects anonymous library usage data from students and applies fundamental statistical methods — Arithmetic Mean, Mean Deviation, and Standard Deviation — to uncover patterns in student library behavior.
  • Subject: Mathematics / Statistics
  • Program: B.Tech CSE (AI & Data Science)
  • Key Concepts: Arithmetic Mean, Mean Deviation, Standard Deviation, Data Visualization, Descriptive Statistics
  • Tools Used: HTML5, CSS3, JavaScript, Chart.js, Tailwind CSS
  • Data Source: Collected from actual library visit records. Each student is assigned an anonymous ID to protect privacy. A single library visit may result in multiple book issues, so book issue entries do not each represent a separate visit.

Formulae Reference

Arithmetic Mean:
x̄ = Σxi / N
Mean Deviation:
MD = Σ|xi − x̄| / N
Population Std. Dev.:
σ = √[ Σ(xi − x̄)² / N ]
Sample Std. Dev.:
s = √[ Σ(xi − x̄)² / (N − 1) ]

N = number of valid (non-empty) values. Empty and invalid cells are excluded. For N = 0 all results are unavailable; for N = 1 the sample standard deviation is undefined.
