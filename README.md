## 📌 About This Project

**Library Insights** is a fully interactive web dashboard that collects library usage data from 15 students and performs statistical analysis to uncover patterns in student library behaviour.

Built as a **Mathematics / Statistics project** for **B.Tech CSE (AI & Data Science)** at **CT University**.

---

## 📊 Features

- ✅ Live Arithmetic Mean, Mean Deviation & Standard Deviation calculations
- ✅ 5 interactive charts (Bar, Pie, Histogram, Grouped Bar)
- ✅ Editable student data table
- ✅ CSV import & export
- ✅ PDF report download
- ✅ Data saved in browser (localStorage)
- ✅ Fully responsive — works on mobile, tablet & desktop

---

## 🧮 Statistical Formulas Used

| Formula | Expression |
|--------|-----------|
| Arithmetic Mean | x̄ = Σxi / N |
| Mean Deviation | MD = Σ\|xi − x̄\| / N |
| Population SD | σ = √[ Σ(xi − x̄)² / N ] |
| Sample SD | s = √[ Σ(xi − x̄)² / (N−1) ] |
